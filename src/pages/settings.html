Passwords

Offer to save passwords
Import passwordsFrom another browser’s passwords export (.csv). In Chrome: Password Manager → Settings → Export passwords. Edge: Settings → Passwords → ⋯ → Export. Safari: File → Export → Passwords. Firefox: about:logins → ⋯ → Export.

Import from another browser

Bookmarks and history come from the browsers on this computer. If you’re signed in to a Google or Mozilla account there, you get everything that account has synced. Nothing is changed in the other browser.

From a bookmarks fileAny browser can export its bookmarks as an .html file.
PasswordsBrowsers lock saved passwords to their own app, so export them there first, then import the .csv file under Passwords.
